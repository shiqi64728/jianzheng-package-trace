# Competition RC v1.1 已知限制

- 没有通过权限和隐私审核的真实同包裹 N1/N2/N3 多表面序列；`REAL_WORLD_CALIBRATION = PENDING_EXTERNAL_DATA`。
- 当前 D02/D03 模型来自单一公开数据域，val mAP50-95 为 0.094648；不得外推为真实快递行业准确率。
- YOLO26s@640 虽有 0.102231 val mAP50-95，但未达到预设 2/3 晋级门槛，未做 candidate test，也未晋级。
- 冻结 split 存在 3 组 perceptual near duplicate 疑似泄漏；0 exact duplicate。该风险已披露，冻结数据未被事后修改。
- D01/D04/D05 仍为开放集变化提示加人工复核，不是自动 AI 分类。
- 视频只做损伤关键帧筛查，不识别抛扔或人员行为。
- 风险引擎仅辅助整理证据，不作法律责任、赔偿或概率结论。
- 强透视、光照、遮挡、反光、背景变化、缺面或配准失败会降低结果可靠性。
- 没有账号体系、企业物流 API、云部署、移动端、实时视频流或自动法律判责；这些不属于 RC v1.1。

> 仅用于异常定位、证据整理和人工责任复核，<br>
