# Competition RC v1.0 已知限制

1. 活动模型只自动支持 D02 表面凹陷与 D03 纸箱破口；D01/D04/D05 不是 AI 自动分类。
2. D02/D03 当前测试集 mAP50-95 较低，RC 业务完善不代表模型 accuracy 提升。本轮没有训练新模型。
3. `UNKNOWN_VISUAL_CHANGE` 只证明达到工程阈值的可靠外观变化，不能自动映射成具体损伤类别。
4. ORB/RANSAC 在低纹理、强反光、遮挡或大视角变化下可能失败；失败结果必须降级为证据不足，不能产生 HIGH 责任风险。
5. 风险分数是九项确定性规则分解的辅助优先级，不是概率，也不是法律责任或赔偿结论。
6. 当前没有真实快递企业 API；物流节点来自匿名 JSON/CSV 通用适配器或受控演示。
7. 当前没有真实同一包裹 N1/N2/N3 多表面序列通过权限和隐私审核；`REAL_WORLD_CALIBRATION = PENDING_EXTERNAL_DATA`。
8. Demo A/D 是合成数据；Demo B/C 使用公开数据并构造模拟节点流程，均不是真实物流轨迹。
9. 视频功能只做 MP4 固定间隔采样、D02/D03 检测、排序和关键帧提取；不识别抛扔、违规动作、人员身份或行为。
10. Dashboard 统计反映当前 SQLite 数据库，其中包括从 v0.2 bootstrap 的历史记录与 RC 验证记录；不是行业总体数据。
11. SQLite 适合单机比赛原型，不提供分布式并发、云高可用或多租户隔离。
12. 没有账号体系、OAuth、云服务器、移动原生 App、实时摄像头流、Redis、PostgreSQL 或消息队列。
13. HTML 报告引用本机外部 runtime 图像；移动报告目录而不移动关联图像会使引用失效。
14. ONNX/ONNX Runtime 是 experimental，当前 active runtime 仍为 PyTorch。
15. 工单事件与人工复核事件 append-only；工单当前状态可更新，但历史事件不能更新或删除。
