# 数据来源策略 v0.1

## 1. 路线调整原因

项目早期以成员 C 人工试采集为主要数据入口。现已获得可追溯的公开数据集和国家邮政局公开统计；继续要求成员 C 大规模拍摄普通损伤图片，会重复投入人力，且难以快速形成类别覆盖、许可证记录和可复现的训练候选。

当前路线调整为：

```text
公开数据集和公开资料为主
＋
少量类别缺口补拍
＋
少量 N1/N2/N3 连续节点验证
```

该调整不废弃 21 字段数据合同、批次初始化工具或图像质量审计器。它们继续用于团队自有或明确授权的补缺采集、真实试验序列和演示数据，而不是用于给公开图片伪造物流业务字段。

## 2. 公开数据为主的来源构成

| 来源 | 主要用途 | 使用边界 |
|---|---|---|
| `defect-cardboard` | `dent`/D02、`hole`/D03 的检测候选 | `dirt` 只能作为 D04 候选，必须人工复核 |
| Damaged Box Detection | 完好/破损二分类候选 | `damagedpackages` 不得直接细分为 D01—D05；旋转增强图不是独立物理包裹 |
| TAMPAR | 参考/篡改外观配对、表面归一化、变化检测研究 | 不得伪造成真实 N1/N2/N3，不得把文件名直接映射为项目损伤类别 |
| 国家邮政局公开统计 | 行业背景、业务量与收入展示 | 不进入图像训练清单 |

所有公开数据进入训练候选前，必须完成来源、许可证、完整性、类别语义、重复及 split 泄漏审计。许可证或证据不足的记录保持阻塞。

## 3. 人工采集保留的必要范围

人工采集只用于已确认的缺口：

1. D01 箱角挤压；
2. D05 胶带变化或疑似二次封装；
3. 能明确证明受潮语义的 D04 样本；
4. 少量自有包裹 N1/N2/N3 连续节点验证序列；
5. 现场演示数据；
6. 公开数据与真实拍摄之间的域差异对照。

补采任务必须说明目标类别、数量上限、纸箱范围、节点定义、隐私要求和验收方法。不得为了达到任意数量目标而重复拍摄普通损伤图。

## 4. 公开数据不能替代的连续节点验证

公开数据可以支持分类、检测、表面归一化或前后变化研究，但通常没有真实的 `package_id`、`sequence_id`、`node_id`、`capture_time` 和 `first_abnormal_node`。因此：

- 数据集名称不能代替 `package_id`；
- 图片文件名不能伪造 `package_id` 或 `sequence_id`；
- 训练 split 不能代替物流 `node_id`；
- TAMPAR reference/tampered 不能强写为 N1/N2；
- 下载时间不能代替 `capture_time`；
- 公开图片不能直接证明责任节点。

连续节点定位必须由少量自有或明确授权包裹，按照预先定义的 N1/N2/N3 流程真实拍摄和复核。

## 5. 成员 A、B、C、D 的新分工

| 成员 | 数据路线阶段职责 |
|---|---|
| 成员 A | 维护数据合同与来源治理规则；下达补采和连续验证任务；批准类别映射；汇总验收结果 |
| 成员 B | 维护公开数据适配、完整性/重复/split 审计及后续训练候选接口；在数据通过治理后选择并验证模型基线 |
| 成员 C | 人工抽查公开数据类别和样本质量；复核 `dirt`、二分类样本和 TAMPAR 配对；仅按明确缺口少量补拍和制作连续节点序列 |
| 成员 D | 维护系统集成、可视化与比赛材料的数据引用；确保行业统计与模型训练数据分离；展示结论不超出证据范围 |

成员 C 不再承担大规模普通破损图片采集、大批量快递站拍摄或个人信息收集。成员分工如有项目负责人后续书面调整，以更新后的正式记录为准。

## 6. 数据使用和许可证边界

- 每个公开来源必须保留来源网址、版本、许可证副本和引用文本；
- 训练、演示和比赛材料按许可证要求署名；
- 使用范围不得超出来源登记中的 `usage_scope`；
- 许可证不明确或引用证据缺失的数据不得进入训练；
- 不移动、覆盖、删除、重新编码或擅自改动公开数据 `raw` 原始文件；
- 不爬取私人运单页面，不收集姓名、电话、地址、运单号或面单图片；
- 国家邮政局统计只用于行业背景和可视化，不混入图像训练数据。

## 7. 后续数据处理流程

公开数据流程：

```text
公开数据下载与来源登记
→ 许可证和类别审计
→ 重复及泄漏检查
→ 类别映射人工复核
→ 训练候选数据
```

人工补充流程：

```text
发现类别或连续节点缺口
→ 提出明确补采任务
→ 成员 C 少量补拍
→ manifest 校验
→ 图像质量审计
→ 人工复核
```

只有同时满足来源可追溯、许可证通过、文件完整、标签语义明确、无跨 split 重复、类别映射获批且用途与任务匹配的数据，才可进入后续训练候选。公开数据不能替代真实连续节点验证，也不能单独形成物流责任认定结论。
